# Cozy Sport · Portfolio Mono

Sexta versión del portfolio de [Cozy Sport](https://cozysport.com/portfolio/): estética monocromática y limpia (gris cálido, negro y blanco), fotografía en blanco y negro y tipografía Jost.

- Sitio: https://juancjose.github.io/cozy-portfolio-mono/
- Tienda: https://cozy-sport.vercel.app

Sitio estático (HTML + CSS + JS, sin build). Cada foto aparece una sola vez en la página. El recorte de portada (`assets/cozy-triatleta-cutout.webp`) se generó con rembg (`isnet-general-use`), con limpieza del fondo entre ruedas y cuadro, escala de grises y fundido a transparente en los bordes recortados de la foto original.

Foto portada: Instagram @seba.ostertag
