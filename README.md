# Cozy Sport · Portfolio Mono

Sexta versión del portfolio de [Cozy Sport](https://cozysport.com/portfolio/): estética monocromática y limpia (gris cálido, negro y blanco), fotografía en blanco y negro y tipografía Jost.

- Sitio: https://juancjose.github.io/cozy-portfolio-mono/
- Tienda: https://cozy-sport.vercel.app

Sitio estático (HTML + CSS + JS, sin build). Cada foto aparece una sola vez en la página. El recorte del ciclista de portada (`assets/cozy-ciclista-cutout.webp`) se generó a partir de `Untitled-2.webp` con rembg (`isnet-general-use`) más limpieza del cielo entre los rayos, en escala de grises con fondo transparente.
